# Demo captures

`range-reality-gate-a.webp` is the 1280×720 visual-gate recording for the
authored 2.5D Range Reality prototype. It was verified in the supported built-in
browser and captured at 1280×720 in local Chrome on 2026-08-31.
`range-reality-gate-a-final.png` is its completed frame,
`range-reality-gate-a-interruption.png` is the separate interruption proof, and
`range-reality-gate-a-report.json` records the measured story and snap timing.

The interaction itself remains the source of truth; these files are review and
submission-preparation artifacts.

`configurator-desktop-webmcp.png` is the final 1280×720 production-build frame
captured in the Codex in-app browser after the licensed live GLB loaded. It
shows the page-defined WebMCP registry reporting all eight agent tools.

`configurator-mobile-production.png` is the final 390 px-wide full-page
production capture (390×3647). It verifies the complete configuration flow,
responsive hero, and sticky review action without horizontal overflow. The
headless capture environment does not expose `document.modelContext`, so its
header truthfully displays Manual mode even though the same build exposes all
eight tools in the supported in-app browser.
